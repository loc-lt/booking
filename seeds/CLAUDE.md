# Seeds

Demo tenants as configuration data: a co-working space, a company office and a sports court.

- Seeds are data, never code. They are applied through the public API or config import.
- If a seed needs special-case code in the core to work, the core is missing a capability: raise it instead of adding the code.
- This is the only folder where product words (co-working, office) are allowed.
- Every seed must apply cleanly in the pipeline.
